JDBC Inventory Management System

A simple Java JDBC project that connects to MySQL to manage product inventory.

Features
- Insert product records
- Search products by category and quantity
- Update product stock and price
- Calculate total inventory value
- Delete products with zero quantity

Technologies
- Java
- JDBC
- MySQL

Database Setup
Create a database named `retail_db` and a table named `Product` with the following fields:

`product_id`, `product_name`, `category`, `quantity`, `price`

How to Run
1. Install Java and MySQL.
2. Add MySQL Connector/J to the project.
3. Update the database username and password in the Java code.
4. Run `InventoryManagement.java`.
